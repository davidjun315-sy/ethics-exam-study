# 철학자 대난투 — 카드 일러스트 제작 규격

카드는 **일러스트가 올라가고 '공개'한 사상가만** 뽑기에 나온다. 일러스트가 없는 카드는 게임에 나오지 않는다.
관리자 → **철학자 카드 관리**(`/admin/game`)에서 사상가마다 프롬프트 복사 · 업로드 · 공개를 한다.

## 1. 후보
- 기출 분석에 **주요·비교 사상가**로 연결된 사상가만 후보가 된다 (분석이 추가되면 자동으로 목록에 나타남, 공개는 수동).
- 표기만 다른 같은 사상가(예: 별칭 겹침)는 관리자 화면에 경고가 뜬다. 하나만 공개하고, 사상가 정리는 '사상가·개념·원전 관리'에서 한다.

## 2. 파일 규격
| 항목 | 값 |
|---|---|
| 비율 | 세로 3:4 (업로드 시 가운데 기준 3:4 로 자동 자름) |
| 저장 | 1200×1600 WebP (업로드 시 자동 변환) |
| 원본 | PNG · JPG · WebP, 15MB 이하, 1200×1600 이상 권장 |
| 구도 | 상반신(가슴 위) 정면~3/4 측면, 얼굴이 위쪽 1/3 지점 |
| 하단 | 아래 25%는 비교적 차분하게 (이름·능력치가 겹쳐 표시됨) |
| 금지 | 글자·로고·테두리·워터마크·실제 사진·다른 화풍 |

## 3. 화풍 (모든 카드 동일)
- 고급 2D 디지털 페인팅, 사실적인 인물 비율, 세련된 채색, 은은한 역광(림 라이트)
- 캐리커처·과장·유치한 만화체 금지 (유머는 필살기 이름·대사에만)
- 배경: 사상을 상징하는 요소를 흐리게 (예: 칸트 — 별이 빛나는 하늘, 장자 — 나비, 플라톤 — 동굴과 빛)
- 같은 프롬프트 틀(관리자 화면의 '프롬프트 복사')을 쓰면 화풍이 맞춰진다

## 4. 외모 근거 (실제 얼굴 반영)
- 관리자 화면 → 사상가 열기 → **ChatGPT용 프롬프트 복사**: 서버가 위키백과에서 대표 초상을 찾아 프롬프트에 넣는다 (사진 첨부 필요 없음)
- 프롬프트는 ChatGPT 에게 ① 먼저 웹에서 실제 초상·흉상을 찾아 얼굴 특징을 정리하고 ② 그 얼굴로, 카드 화풍·구도에 맞춰 그리라고 지시한다
- 완성 그림을 **완성 그림 올리기**로 올리면 3:4 WebP 로 저장되고, 참고한 초상은 '일러스트 메모'에 자동으로 적힌다
- (실험) **Gemini 로 바로 생성**: GEMINI_API_KEY 로 참고 초상을 넣어 바로 그린다 (키의 이미지 생성 한도·요금에 따라 안 될 수 있음, 모델은 GEMINI_IMAGE_MODEL)
- 사상가별 대표 초상과 알려진 얼굴 특징이 프롬프트에 함께 들어간다 (`src/lib/game/suggestions.ts` 의 FACES)
- 초상화·흉상·전통 도상이 있으면 참고 → '일러스트 근거: 초상·조각·도상 참고'
- 확인된 초상이 없거나 후대 상상화뿐이면(고대 동양 사상가 등) → '재구성' (카드 상세에 "재구성한 일러스트" 표시)
- **생존 인물**(예: 싱어·샌델·하버마스·누스바움·길리건·리코나)은 사실적인 얼굴을 그리지 말고 실루엣·뒷모습·상징 중심으로 (프롬프트에 자동 포함)
- 20세기 인물은 사진을 참고해도 되지만 사진을 그대로 쓰거나 사진처럼 보이게 하지 않는다

## 5. 순서
1. `/admin/game` 에서 사상가를 열고 **제안 채우기** → 등급·능력치·필살기·대사 확인
2. **프롬프트 복사** → 이미지 생성 AI 에서 생성 (마음에 들 때까지)
3. **일러스트 올리기** → 미리보기 카드로 확인 → **뽑기에 공개** 체크 → 저장
4. 처음에는 등급이 고루 섞이게 8~12장 정도로 시작해 품질을 맞춘 뒤 늘린다 (배틀은 공개 카드 3장부터 열림)
